# Carnage

An activity sharing system for people who want to discover the people in their community.

## Getting Started

### Prerequisites

- Java 21
- PostgreSQL

The project uses the Gradle wrapper (`./gradlew`), which automatically downloads the required Gradle version.

### Building

```bash
./gradlew build
```

### Running

```bash
./gradlew bootRun
```

### Testing

```bash
./gradlew test
```
