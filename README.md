# Carnage

An activity sharing system for people that want to discover the people in their community.

## Getting Started

### Prerequisites

- Java 21
- Gradle 9.3+
- PostgreSQL

### Building

```bash
./gradlew build
```

### Running

```bash
./gradlew bootRun
```

### Testing

```bash
./gradlew test
```
